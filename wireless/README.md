# Wireless

WiFi 7 + BT 5.4 via M.2 E-key.

## Module

**MediaTek MT7925** preferred. Reasons:
- BE200 has known interop issues on AMD platforms (verify current Intel firmware before reconsidering)
- MT7925 has good mainline kernel support

## Antennas

Two-antenna setup, routed through hinge to lid. Antenna gain pair sourced from Pulse Electronics or Taoglas.
